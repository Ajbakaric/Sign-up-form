##  Getting Started

1. Clone this repo:
   ```bash
   git clone https://github.com/Ajbakaric/Sign-up-form.git
   cd Sign-up-form
   ```

2. Open `index.html` in your browser to view the form.

> ⚠️ If you're using Live Server, it may not auto-launch — manually open:
> `http://127.0.0.1:5500/index.html`
